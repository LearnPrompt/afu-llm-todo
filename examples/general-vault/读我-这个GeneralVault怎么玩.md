# 这个演示 Vault 怎么玩

这里是给 Afu 本地演示用的安全 vault，不是你的真实 `All About Me`。

当前目录含义：
- `00_收件箱/`：放待处理素材。阿福会从这里识别候选。
- `30_整理Wiki/`：放 Wiki packet、整理日志和中间判断。
- `40_行动卡片/`：放被接受后的行动卡片。
- `99_系统/归档/行动卡片/`：放作废或归档的行动卡片。

当前演示素材覆盖：
- 知识管理：QuickNotes、Ideas、Daily、课程笔记、长期上下文。
- 工作学习：深度工作、作业拆分、项目里程碑、求职材料、作品集发布。
- 日常生活：运动恢复、饮食规则、家务补给、账单订阅、关系跟进。
- 周期任务：daily task、weekly task、monthly check、周复盘和下周三件事。

推荐使用顺序：
1. 打开 `http://localhost:4317`。
2. 看“收件箱候选”，选择一条素材。
3. 先“转卡”或“导入”，看它怎么变成行动卡片。
4. 给卡片排日期和时间。
5. 回到这个文件夹，看 Markdown 是否写到了 `40_行动卡片/`。

这套演练的重点不是做真正的任务管理，而是看 Afu 能不能把“乱材料”变成“可执行的一步”。
