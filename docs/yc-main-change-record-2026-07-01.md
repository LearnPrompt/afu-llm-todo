## 具体改动

### 1. 工作区默认目录

- 默认行动卡目录从 `15_自媒体/选题库` 改为 `40_行动卡片`。
- 默认归档目录改为 `99_系统/归档/行动卡片`。
- 默认 Wiki 目录改为 `30_整理Wiki`，index 和 log 路径同步调整。
- 配置测试同步更新。
- 收件箱或 Wiki Todo 目录尚未建立时返回空列表，不再因 `ENOENT` 中断首次配置。

### 2. 排期可靠性

- 排期、撤回排期、作废和撤回转卡等写操作增加按卡片路径执行的 mutation lock。
- 保存排期时增加 `scheduleSubmitting` 状态和“保存中…”反馈，防止重复提交。
- 只有排期 API 成功后才关闭弹窗并继续下一张排期卡。
- 排期结果会把日历提供方、同步状态、macOS 日历名和事件 ID 回写到 Markdown 与操作日志。

### 3. 外部日历失败降级

- 本地 Markdown 改为主数据，外部日历作为可降级同步目标。
- 外部日历创建失败时，本地排期仍会保存，不再让 `/api/topics/schedule` 整体失败。
- 同步失败原因写入 `calendar_sync_status`，前端明确提示“排期已保存，但外部日历同步失败”。
- 切换成“只写 Markdown”时会尝试清理旧外部事件；清理失败不阻断本地保存。

### 4. macOS Calendar

- 新增 `GET /api/macos/calendars`，读取 Calendar.app 的日历及其可写状态。
- 设置页把 macOS 日历名从手工输入改为下拉选择，只展示可写日历。
- 下拉补充加载中、读取失败、无可写日历和保留旧配置等状态。
- 未指定日历时只选择第一个可写日历。
- 指定日历不存在或只读时返回明确错误，不再静默改写其他日历。
- 创建事件后记录实际日历名和事件 UID。
- 删除或重新排期时，可根据 UID 或 `topic_id` 清理旧事件，减少重复日程。
- AppleScript 按本机日期和时间创建事件，避免固定时区转换带来的偏移。

### 5. 转卡流程

- 转卡成功后先显示“转卡完成”弹层，不再直接强制进入排期。
- 用户可以选择“先放排期池”或“现在排期 / 逐条排期”。
- 增加单条和批量结果列表、失败数量、合并到已有卡片的说明。
- 移除 Toast 与 Dialog 的重复成功反馈。
- 新增“撤回转卡”，可删除刚生成的行动卡，让原始收件箱素材重新进入候选池。

### 6. 排期与作废交互

- 加宽排期弹窗，让时间、同步目标和当天已有排期更容易阅读。
- 每日收件箱、排期、作废、飞书授权和转卡结果弹窗统一使用圆形 `×` 关闭按钮。
- 撤回排期时询问是否同步删除外部日历事件。
- 作废界面明确区分“拒绝”和“归档”：拒绝保留行动卡，归档把行动卡移出活动目录。
- 提示文案分别说明 Markdown、飞书和 macOS 的同步结果。

### 7. 暗色模式

- 为每日收件箱、授权信息、转卡结果、当天排期、日历列、容量标签、快捷时段、原因标签、空状态和关闭按钮补齐暗色 surface。
- 修复排期池分页栏在暗色模式下仍使用浅色背景、导致文字对比度过低的问题。
- 新增语义化 `--control-surface` 变量，亮色与暗色模式分别使用对应渐变，边框统一使用 `--line`。

### 8. 示例 Vault 与测试记录

- 新增 General、Study、Weekend 三套示例 Vault。
- 增加 Vault 切换、使用计划、连接说明，以及行动卡、Wiki、归档和 planner log 示例。
- 保留一次真实 macOS 排期记录：行动卡“20 作品集发布前检查清单怎么拆任务”已排到 2026-06-29 20:00–20:30，并写入 `Default` 日历。
- `package-lock.json` 纳入版本管理。

### 9. 文档整理

- 原来的“当前状态与测试计划”和“YC 改动记录”合并为本文。
- README 只保留一个入口。
